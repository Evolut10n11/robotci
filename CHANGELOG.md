## 0.1.0a1 — 2026-09-21

First public alpha, distributed from the repository.

- External-user quickstart and a runnable three-route Nav2 Loopback example.
- Package metadata and CLI version aligned at `0.1.0a1`.
- Wheel build/install smoke workflow and structured bug/pilot feedback forms.

The alpha includes the existing runner, strict YAML configuration, metrics and
evidence checks, local baselines, deterministic regression gating, reproducibility
contracts, GitHub Action reports, replay viewer, application API, and read-only MCP.

This is an alpha package milestone, not a stable PyPI release or a completed
external-team validation claim.
