# Импорт описания робота

В локальном replay откройте **«Описание робота»**, вставьте описание или выберите
файл, затем нажмите **«Распознать и встроить»**. Выбор модели меняет только
представление в 3D. Исходные результаты, траектории и официальный gate не меняются.

## Поддерживаемый первый набор

- URDF: одно связное дерево link/joint, fixed/revolute/continuous/prismatic,
  origin xyz/rpy, axis, пределы, box/sphere/cylinder и ссылки на меши.
- MJCF: развёрнутый файл одного робота, body, hinge/slide/freejoint, default и
  childclass, quat/euler/axisangle, единицы углов, home/stand, базовые geom и меши.
- YAML: явный идентификатор `robot.model` из локального каталога.

```yaml
robot:
  model: unitree_go2
```

Идентификаторы: `unitree_go2`, `unitree_g1`, `franka_emika_panda`. Это модели
реальных роботов из закреплённой версии MuJoCo Menagerie, с исходными мешами и
опорной позой. Они включены в пакет и не скачиваются при просмотре. Файлы лицензий
находятся рядом с каталогом. Геометрия сжата для передачи; свариваются только
дублирующие вершины с допуском 1e-8, без изменения силуэта на уровне просмотра.

В полноценном `robotci.yaml` поле `robot.model` также допустимо. Оно сохраняется
как presentation metadata в replay при следующем запуске, после чего просмотрщик
автоматически открывает соответствующую геометрию. Оно **не выбирает физическую
модель симулятора или контроллер**: существующий runtime остаётся Nav2. Для другой
системы управления нужен отдельный адаптер.

## Автоматическое распознавание

Только точное совпадение SHA-256 нормализованного текста MJCF с закреплённым
описанием позволяет автоматически подставить оболочку из каталога. Изменённое
описание не заменяется похожей моделью: отображается его собственная структура.
Название `G1` или `Go2` само по себе ничего не доказывает. Для остальных описаний
определяется приблизительный тип по суставам и структуре. Уровни уверенности
высокий/средний/низкий являются эвристиками, не статистической вероятностью.

По произвольному YAML с одними скоростями и параметрами контроллера нельзя
восстановить геометрию. В таком случае приложение просит URDF/MJCF вместо догадки.

## Свои меши

Выберите папку с описанием и файлами OBJ/STL. Сохраняется структура относительных
путей; `package://` сопоставляется только с однозначно найденными локальными
файлами. Несколько одинаковых имён не разрешаются случайным выбором. Меши остаются
в памяти браузера, сервер получает только текст описания. Внешние URL не
загружаются. MTL/текстуры и DAE пока не поддерживаются.

Когда мешей нет, видны доступные примитивы, collision-геометрия MJCF и
кинематический каркас. Это явно отмеченная частичная визуализация, не точная
оболочка и не сертификат совместимости. В 2D пока сохраняется условный маркер.

## Границы и безопасность

Модели показываются в опорной позе. Они не начинают ходить, балансировать или
захватывать предметы от одного импорта. Суставные траектории из URDF не выводятся
и не придумываются из Nav2-позиций. Положение визуальной модели привязывается к
записанной траектории; суставы остаются в опорной позе.

Импорт не выполняет Xacro, shell-подстановки, XML-инструкции, DTD, плагины, внешние
include, frame/attach/composite/flex и equality-решатель. Неподдерживаемые
конструкции отклоняются или отдельно отмечаются (статические equality/tendon).
Для scene.xml с include выберите развёрнутый файл робота, например go2.xml.

Лимиты: 2 МиБ текста, 256 звеньев, глубина 48, 24 МиБ на меш и 128 МиБ/512 файлов
на выбранную папку. Серверный импорт требует локального origin и токена сессии,
не предоставляет произвольного чтения файлов и не записывает конфигурацию на диск.
Смена модели в диалоге действует только в текущей сессии. «Из записи» отменяет её.

## Повторяемая проверка каталога

`scripts/build_robot_catalog.py` проверяет хеши закреплённых исходных каталогов.
`web/build-robot-catalog.mjs` создаёт самодостаточные GLB из исходных OBJ/STL.
`scripts/verify_robot_catalog.py` сравнивает опорные системы координат звеньев с
реальной forward kinematics MuJoCo. Браузерный сценарий
`experiments/robot_models/import_acceptance.py` проверяет вставку, авто-выбор,
неизменность replay и отсутствие внешних сетевых запросов.

Источники форматов: ROS URDF и MuJoCo MJCF. Каталог:
https://github.com/google-deepmind/mujoco_menagerie/tree/0059d4335f8156206f63a35662313385f7ad6d74
